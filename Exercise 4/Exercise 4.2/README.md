# Exercise 4.2: D3 Page Elements

This exercise demonstrates how to use D3 to change the appearance of HTML elements, append new content to the page, and add SVG elements.

## Files

- `index.html` contains the energy consumption webpage.
- `style.css` contains the page styling.
- `js/main.js` contains the D3 code.

## D3 Tasks Completed

- Loaded the D3 v7 library in `index.html`.
- Loaded a separate D3 code file: `js/main.js`.
- Used `d3.select()` to change the style of the `h1` element.
- Used `d3.selectAll()` to style all `h2` headings.
- Used D3 to append a new paragraph to the `.container` section.
- Used D3 to append a visible rectangle to the SVG.
