# Exercise 4.1: Drawing SVGs

This exercise demonstrates how to create and style SVG shapes in HTML. The webpage contains a customised SVG house and garden scene, plus annotated screenshots explaining how SVG coordinates match the drawing.

## Files

- `index.html` contains the SVG drawing and explanations.
- `style.css` contains the page styling.
- `images/` contains annotated screenshots of SVG shapes.

## SVG Shapes Used

The drawing uses the following SVG elements:

- `rect` for the sky, grass, house body, door, chimney, tree trunk, and windows.
- `circle` for the sun, door handle, tree leaves, and flowers.
- `ellipse` for the cloud and pond.
- `line` for the fence and window details.
- `polyline` for the garden path.
- `polygon` for the roof.
- `text` for the drawing label.
- `g` to group and style the two windows together.

## Coordinate Annotations

The webpage includes annotated screenshots for:

- Rectangle coordinates: `x`, `y`, `width`, and `height`.
- Circle coordinates: `cx`, `cy`, and `r`.
- Polygon points for the roof.
- Line coordinates: `x1`, `y1`, `x2`, and `y2`.

## Customisation

The final SVG scene was customised by changing colours, adding clouds, birds, flowers, fence posts, a pond, a path, a chimney, detailed grouped windows, and a personalised label.
