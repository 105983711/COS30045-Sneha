# Exercise 5.1: Vertical Bar Chart with Axis

## Overview

This exercise creates a vertical bar chart using D3.js. The chart compares the average labelled energy consumption of 55 inch TVs by screen technology.

The purpose of this exercise is to practise loading CSV data, creating scales, drawing SVG bars, and adding axes to a D3 visualisation.

## Files

- `index.html` - Main webpage for Exercise 5.1
- `css/style.css` - Styling for the page and chart
- `js/barChart.js` - D3 code used to create the vertical bar chart
- `data/Data_exercise 5.1.csv` - Dataset used for the chart

## Features

- Loads data from a CSV file
- Converts screen technology names to uppercase
- Sorts energy consumption values from highest to lowest
- Uses a band scale for the x-axis
- Uses a linear scale for the y-axis
- Adds x-axis and y-axis
- Displays labelled bars showing energy consumption in kWh

If the CSV does not load by double-clicking the file, open the folder using Live Server in VS Code.
