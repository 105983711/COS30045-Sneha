# Exercise 5.3: Donut Chart

## Overview

This exercise creates a donut chart using D3.js. The chart shows the proportion of small, medium, and large TV models in the prepared TV dataset.

The purpose of this exercise is to practise using D3's pie generator and arc generator to create a circular chart.

## Files

- `index.html` - Main Exercise 5.3 donut chart page
- `customised-donut.html` - Customised version of the donut chart
- `css/style.css` - Styling for the page and donut charts
- `js/donut-chart.js` - D3 code for the original donut chart
- `js/customised-donut.js` - D3 code for the customised donut chart
- `data/Data_exercise 5.3.csv` - Dataset used for the donut charts

## Features

- Loads screen size category data from CSV
- Uses D3's pie generator to calculate slice angles
- Uses D3's arc generator to draw donut slices
- Uses an ordinal colour scale
- Adds labels to the donut chart
- Displays the proportion of TV models by screen size category

## Customised Donut

The customised donut chart changes the original chart by adding:

- A custom colour scheme
- Rounded slice corners
- Spacing between slices
- Percentage labels
- A larger centre hole
- Centre text showing the total number of TV models
